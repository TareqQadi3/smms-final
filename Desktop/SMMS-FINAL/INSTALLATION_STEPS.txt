المتطلبات: Docker Desktop فقط
──────────────────────────────────────────────────────────────

الخطوة 1: حمّل Docker Desktop
  → اذهب إلى: https://www.docker.com/products/docker-desktop/
  → اختر: Download for Windows
  → ثبّته وأعد تشغيل الكمبيوتر

──────────────────────────────────────────────────────────────

الخطوة 2: افتح PowerShell في مجلد المشروع
  → افتح مجلد smms-final على سطح المكتب
  → افتح مجلد Desktop ثم SMMS-FINAL
  → اضغط زر يمين على مساحة فارغة داخل المجلد
  → اختر "Open in Terminal" أو "فتح في Terminal"

──────────────────────────────────────────────────────────────

الخطوة 3: اكتب هذين الأمرين فقط

  copy .env.example .env
  docker compose up -d --build

  (الأمر الأول مرة واحدة فقط)
  (الأمر الثاني عند كل تشغيل)

──────────────────────────────────────────────────────────────

الخطوة 4: انتظر 3-5 دقائق
  (يقوم Docker بتحميل وبناء كل المكونات)
  للتحقق من الحالة اكتب: docker compose ps

──────────────────────────────────────────────────────────────

الخطوة 5: افتح المتصفح
  → http://localhost

──────────────────────────────────────────────────────────────

الخطوة 6: سجّل الدخول
  Username: sysadmin
  Password: Admin@1234

✅ النظام يعمل!

════════════════════════════════════════════════════════════════

أوامر مفيدة:

  docker compose ps           ← عرض حالة الخدمات
  docker compose logs -f      ← عرض السجلات
  docker compose down         ← إيقاف النظام
  docker compose down -v      ← إيقاف وحذف البيانات (إعادة ضبط كاملة)

════════════════════════════════════════════════════════════════

مشاكل شائعة:

❌ "port is already allocated"
✅ اكتب: docker compose down -v
   ثم: docker compose up -d --build

❌ الصفحة لا تفتح؟
✅ انتظر دقيقتين إضافيتين ثم اضغط F5
   أو تحقق من الحالة: docker compose ps

❌ Docker لا يعمل؟
✅ تأكد أن Docker Desktop يعمل (أيقونته في شريط المهام)
   ثم أعد تشغيل Docker Desktop
